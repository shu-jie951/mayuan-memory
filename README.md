# 马原记忆舱

马克思主义基本原理题库学习网站：把每一道题，变成长期记忆。

## 功能

- **选择题背诵 / 主观题背诵**：按题库顺序或记忆优先排序，四档自评（重来 / 模糊 / 记住 / 熟练）驱动间隔复习计划
- **选择题盲考**：自定义考试范围、题数（预设 10/20/50/全部 或自定义）与时长（0–300 分钟），智能强化组卷优先照顾薄弱题；交卷前不显示答案，刷新不丢进度，限时到自动交卷
- **错题本与章节专项**：错题自动进入重考，可按章节专项突破
- **学习统计**：14 天学习打卡热力图、今日记忆次数与每日目标
- **成绩导出**：考试结果一键复制或导出 CSV（UTF-8 BOM，Excel 直接打开）
- **键盘快捷键**：背诵模式 `Space` 显示答案、`1–4` 自评、`←/→` 翻题、`F` 收藏；考试模式 `A–H` 选答案、`Enter` 下一题、`Backspace` 上一题
- **离线可用（PWA）**：进度保存在本机浏览器，支持添加到主屏幕、离线学习与数据备份导入导出

## 数据

题库来自九份 Word 题库文档，经 `tools/` 下脚本解析、去重合并为 `data/questions.js`（共 421 道选择题及主观题，含章节归属与合并来源记录）。

## 本地运行

纯静态站点，无任何构建依赖：

```bash
npm start        # 或直接双击 index.html / 用任意静态服务器
```

运行测试（Node.js 内置测试运行器）：

```bash
npm test
```

## 技术栈

原生 HTML / CSS / JavaScript，零依赖。记忆算法基于间隔重复（四次自评对应不同复习间隔），所有进度通过 `localStorage` 保存在本机。
